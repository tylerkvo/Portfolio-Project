# Purpose

This document describes the high-level architecture of tylerkvo.com. It will evolve as the application grows and new technologies are introduced.

---

# Current Architecture

Current Stack:

Browser
↓
React
↓
GitHub Pages

The application is currently a client-side React application hosted on GitHub Pages.

---

# Future Architecture

The long-term architecture may include:

- Frontend (React + Vite)
- API Layer
- Backend Services
- Database
- Authentication
- External APIs (Sleeper, Maps, etc.)
- CI/CD Pipeline
